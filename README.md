# Kakeya Conjecture: Lecture Report

An independently written expository report on Joshua Zahl's talk, **The Besicovitch compression phenomenon and the Kakeya set conjecture**.

## Read the complete report

**[Download / read the seven-page PDF](kakeya-lecture-report.pdf)**

The report reconstructs the lecture from fourteen blackboard photographs and adds connecting explanations. It introduces the Kakeya set conjecture and its tube formulation, then explains connections with Fourier multipliers, restriction theory, and the free Schrödinger equation.

## Topics

- Besicovitch sets, dimension, and the Kakeya set conjecture
- Discretization using thin tubes
- Fefferman's ball multiplier example and Besicovitch compression
- Stein's Fourier restriction conjecture and wave packets
- The free Schrödinger equation and the extension operator
- The Convex Wolff Axiom and the theorem discussed in the lecture

This repository presents the author's study and exposition of Joshua Zahl's lecture. The mathematical results discussed are attributed to the researchers named in the report, including Wang and Zahl.
